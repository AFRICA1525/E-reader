    Автор: Сайлауқызы  Жұлдыз

    Дәрістер ЖОО-да объектілі-бағытталған бағдарламалауды үйренушілерге, сондай-ақ Java бағдарламалау тілін өз бетінше үйренгісі келетіндерге арналған. Видео дәрістерде негізгі деректер түрлерін, басқару нұсқаулықтарын, Java-да класстар мен объектілерді сипаттау ерекшеліктерін, пакеттер мен интерфейстерді құру, әдістер мен мұраларды жүктеу, соның ішінде, Java-да бағдарламаларды тиімді жасау үшін қажетті барлық негізгі тақырыптарды қамтиды.

    Java бағдарламалау тілін оның классикалық көрінісінде меңгеруге, сондай-ақ Java тілінде объектілі-бағытталған бағдарламалау технологиясын меңгеруге мүмкіндік береді. 

    “Объектіге бағытталған бағдарламалау” оқу құралы 6В06301  «Ақпараттық қауіпсіздік жүйелері» мамандығының және 6B061 "Ақпараттық-коммуникациялық технологиялар" дайындау бағытының оқу процесінде қолданылуы мүмкін.

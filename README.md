# JAVA — электронды оқу құралы, 2026

Читалка сразу открывает output/pdf/java-reader.pdf. Книга заканчивается списком литературы. Обложка открывается отдельно на компьютере и телефоне, затем на ПК страницы отображаются разворотами по два листа, на телефоне — по одному. Основной текст и тесты набраны кеглем 12 с выравниванием по ширине. Доступны перелистывание, оглавление, увеличение и полный экран. При открытии показывается отдельная обложка. Теория, практика и тесты в оглавлении сворачиваются. Панель масштаба скрывается через 3 секунды бездействия и появляется при нажатии на её область или кнопку увеличения. Названия лекций открывают видеосабақ в новой вкладке. Интерфейс на казахском языке.

На телефоне кнопки перелистывания находятся в нижней панели, оглавление открывается на весь экран, а числовая клавиатура помогает перейти к странице. Свайп перелистывает разворот на ПК или одну страницу на телефоне. Перелистывание сопровождается изгибом листа, включая телефоны. При перетаскивании следующая страница заранее появляется под сгибом; отмена свайпа возвращает текущий лист без изменения позиции. Увеличенную страницу можно перемещать пальцем или мышью. Масштаб 100–400% регулируется кнопками, ползунком, жестом двумя пальцами или Ctrl + колёсиком. Процент масштаба служит кнопкой сброса к целому листу. Увеличение сохраняется при перелистывании. Учитываются безопасные отступы экрана. В адресах CSS и основного JavaScript указан номер версии для обновления браузерного кэша после деплоя.

## Содержание

15 лекций (15-я подготовлена по лабораторной работе №15), практическая часть, 100 тестовых вопросов в 10 тематических группах и ключ ответов, результаты обучения, глоссарий, заключение, литература. Обложка, предисловие, тесты, заключение и литература обновлены из файлов NewPages. Оглавление автоматически пересчитано и содержит ссылки. Каждая тема начинается с новой страницы. Исходный PDF сохранён, новая версия набрана заново. Формулы исходника с нестандартными символами сохранены изображениями.

В исходнике встречаются JavaScript, C++ и MATLAB; пояснения отделяют их от Java. Источники видео и документации перечислены в литературе. Для главы с MATLAB дан дополнительный урок о библиотеках Java и официальная документация MATLAB: проверенного казахского видео именно о MATLAB не найдено.

## Запуск

node server.mjs — затем http://127.0.0.1:5173. Установка npm-пакетов не нужна. Открывайте сайт через HTTP.

Для статического хостинга сохраните index.html, CSS/JS, vendor, assets и output/pdf с исходной структурой. Исходный PDF и Python-скрипты для чтения не требуются.

## Подготовка книги

python scripts/build_book.py создаёт PDF, карту оглавления book.json и задания assessment.json. Нужны исходный PDF, файлы NewPages, python-docx, pypdf, pdfplumber, pypdfium2, reportlab, Pillow и шрифты Windows. Проверенные метаданные видео: tmp/pdfs/video-metadata.json.

python scripts/verify_book.py проверяет формат страниц, границы текста, год, символы, ссылки, задания и начало тем. Результат: output/pdf/verification.json и изображения всех страниц в tmp/pdfs для визуальной проверки. JavaScript: npm run check.

PDF.js хранится локально в vendor. Шрифты встроены в книгу. Звук: Mixkit «Page turn single» (1104), https://mixkit.co/free-sound-effects/paper/ ; лицензия https://mixkit.co/license/#sfxFree . При системном предпочтении уменьшенной анимации звук и анимация отключаются.

Проверка двух пальцев и перемещения: node scripts/check-reader-gestures.mjs (события обработчиков в изолированной модели DOM; не заменяет проверку на физическом устройстве).

# Лист — читалка книги JAVA

Сайт сразу открывает подготовленную книгу `output/pdf/java-reader.pdf`. Карта `output/pdf/book.json` задаёт обычные страницы и целые развороты; повторный автоанализ для этой книги не выполняется.

## Книга

Исходный PDF сохранён без изменений. В отдельной копии — 184 обычные страницы и 14 целых листов (обложка, вводные сведения, содержание, общие таблицы/схемы). 104 старых общих колонтитула удалены из команд PDF; компактный заголовок добавлен внутри границ каждой новой страницы. Текст и векторная графика сохранены.

Внутренние ссылки и оглавление переназначены на новый PDF. Напечатанные в исходнике номера в тексте содержания сохранены; нажатие использует исправленные ссылки.

Целиком сохранены исходные листы 1, 2, 3, 17, 53, 54, 63, 69, 78, 97, 98, 99, 104, 105. Остальные разделены пополам.

## GitHub Pages

Загрузите файлы сайта и папки `vendor`, `assets`, `output` с сохранением структуры. `index.html` должен быть в корне опубликованной папки. Относительные пути работают в подпапке репозитория.

Node.js, npm и сборка для GitHub Pages не нужны. Исходный PDF, видео и `server.mjs` для опубликованного сайта не требуются.

## Локальный запуск

Нужен HTTP-сервер; двойной щелчок по `index.html` не подходит. Если Node.js установлен: `node server.mjs`, затем http://127.0.0.1:5173. npm и установка пакетов не требуются.

На этом компьютере можно использовать Node.js из среды Codex. Команды для PowerShell:

```powershell
cd "C:\Users\zzzaa\Desktop\Chitalca"
& "C:\Users\zzzaa\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" server.mjs
```

Путь среды Codex может измениться после обновлений. Если сервер уже запущен, повторный запуск не нужен.

## Чтение

Свайпы перелистывают цельный лист; место захвата влияет на изгиб. Короткий жест отменяется. Звук бумаги включён по умолчанию, срабатывает во время подтверждённого переворота и отключается в настройках. Предпочтение сохраняется.

На телефоне обычные страницы показываются по одной. Общие таблицы/схемы — целиком; двойное нажатие увеличивает страницу, после чего её можно перемещать пальцем. Есть миниатюры, поиск, закладки, сохранение позиции, масштаб, тёмная тема, полный экран и переходы по Мазмұны. Поиск не распознаёт текст сканов без OCR.

В настройках можно открыть другой PDF. Для сторонних файлов сохраняются эвристическое авторазделение и ручное решение для отдельного листа. Файлы обрабатываются в браузере и не отправляются на сервер; позиция и закладки хранятся в localStorage.

PDF.js 4.10.38 и pdf-lib 1.17.1 находятся в `vendor`. Запись Mixkit «Page turn single» (1104) находится в `assets/page-turn.mp3`: https://mixkit.co/free-sound-effects/paper/ ; лицензия https://mixkit.co/license/#sfxFree . Дополнительные таблицы символов/стандартные шрифты PDF.js при необходимости загружаются с jsDelivr; интерфейс использует Google Fonts с системной заменой.

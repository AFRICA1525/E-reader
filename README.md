# JAVA — электронды оқу құралы, 2026

Читалка сразу открывает output/pdf/java-reader.pdf. На компьютере — два книжных листа, на телефоне — одна страница во всю ширину. Доступны перелистывание, оглавление, увеличение и полный экран. Позиция сохраняется локально. Названия лекций открывают видеосабақ в новой вкладке. Интерфейс на казахском языке.

На телефоне кнопки перелистывания находятся в нижней панели, оглавление открывается на весь экран, а числовая клавиатура помогает перейти к странице. Свайп перелистывает один лист. Увеличенную страницу можно перемещать пальцем; на коротком экране доступна вертикальная прокрутка. Учитываются безопасные отступы экрана. В адресах CSS и основного JavaScript указан номер версии для обновления браузерного кэша после деплоя.

## Содержание

15 лекций (15-я подготовлена по лабораторной работе №15), практическая часть, 150 теоретических вопросов с уровнями 3/4/3, 75 практических заданий, результаты обучения, глоссарий, заключение, литература и приложения Java. Тесты не включены. Каждая тема начинается с новой страницы. Исходный PDF сохранён, новая версия набрана заново. Формулы исходника с нестандартными символами сохранены изображениями.

В исходнике встречаются JavaScript, C++ и MATLAB; пояснения отделяют их от Java. Источники видео и документации перечислены в литературе. Для главы с MATLAB дан дополнительный урок о библиотеках Java и официальная документация MATLAB: проверенного казахского видео именно о MATLAB не найдено.

## Запуск

node server.mjs — затем http://127.0.0.1:5173. Установка npm-пакетов не нужна. Открывайте сайт через HTTP.

Для статического хостинга сохраните index.html, CSS/JS, vendor, assets и output/pdf с исходной структурой. Исходный PDF и Python-скрипты для чтения не требуются.

## Подготовка книги

python scripts/build_book.py создаёт PDF, карту оглавления book.json и задания assessment.json. Нужны pypdf, pdfplumber, pypdfium2, reportlab, Pillow и шрифты Windows. Проверенные метаданные видео: tmp/pdfs/video-metadata.json.

python scripts/verify_book.py проверяет формат страниц, границы текста, год, символы, ссылки, задания и начало тем. Результат: output/pdf/verification.json и изображения всех страниц в tmp/pdfs для визуальной проверки. JavaScript: npm run check.

PDF.js хранится локально в vendor. Шрифты встроены в книгу. Звук: Mixkit «Page turn single» (1104), https://mixkit.co/free-sound-effects/paper/ ; лицензия https://mixkit.co/license/#sfxFree . При системном предпочтении уменьшенной анимации звук и анимация отключаются.

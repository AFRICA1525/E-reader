# Лист — PDF-читалка

Локальное веб-приложение. Запуск: `node server.mjs`, затем http://127.0.0.1:5173. Можно также запустить `npm start`, если npm установлен. Сборка не нужна.

Возможности: выбор PDF и drag & drop, анимированные развороты, одностраничный вид на телефонах, свайпы, миниатюры, поиск по текстовому слою, закладки и сохранение позиции в браузере, масштаб, тёмная тема, полноэкранный режим, звук страниц, загрузка исходника и экспорт разделённых страниц.

Авторазделение: горизонтальные листы с шириной/высотой ≥ 1,2 делятся на левую и правую половину. Это эвристика: горизонтальную презентацию она тоже может разделить. В настройках доступны «Не разделять» и «Каждый лист пополам». Исходник сохраняется без изменений. Разрез по центру; нестандартные развороты с асимметричными страницами потребуют ручной подготовки.

PDF обрабатывается в браузере и не загружается на сервер. Закладки и позиция хранятся в localStorage, сами документы не сохраняются. Поиск не распознаёт текст сканов (OCR не подключён). Очень большие документы могут расходовать много памяти. Для защищённого PDF чтение поддерживает пароль; экспорт может быть недоступен.

PDF.js 4.10.38 и pdf-lib 1.17.1 хранятся в vendor. Дополнительные карты символов и стандартные шрифты PDF.js, при необходимости, загружаются с jsDelivr; шрифты интерфейса — Google Fonts (при отсутствии сети используются системные). Лицензии библиотек находятся в их заголовках. Пример использует PDF в папке проекта.

Клавиши: ←/→ — страницы, F — полный экран, +/− — масштаб, Escape — закрыть панели.

На телефоне боковые стрелки скрыты: тяните страницу влево/вправо. Незавершённый жест возвращает страницу назад; при увеличении жесты перемещают документ. Анимация изгибает лист по полосам canvas и реагирует на движение пальца. При включённом системном уменьшении движения перелистывание происходит без анимации.

Если таблица или картинка занимает обе половины, откройте настройки и нажмите «Показать этот разворот целиком». Исключение сохраняется для этой книги, применяется к экспорту и отменяется кнопкой «Разделить этот разворот на страницы». Такие случаи в сканах автоматически не распознаются.

Во время чтения кнопка открытия PDF скрыта. Другая книга открывается через настройки.

Перелистывание зависит от высоты захвата: верх/центр/низ страницы дают разные изгибы. Детализация сетки адаптивно снижается на медленных устройствах.
Звук включён по умолчанию; отключение сохраняется в браузере. Используется запись Mixkit «Page turn single» (1104), с тремя вариантами скорости/громкости. Источник: https://mixkit.co/free-sound-effects/paper/ ; лицензия: https://mixkit.co/license/#sfxFree . Файл хранится локально в assets/page-turn.mp3. При публикации загрузите page-sound.js и папку assets. Звук появляется после взаимодействия с сайтом и воспроизводится только при подтверждённом перелистывании.

Анимация теперь использует одну связную WebGL-поверхность с общей текстурой: 128×16 ячеек, один вызов отрисовки на кадр, без независимых фрагментов и швов. При отсутствии WebGL используется цельный лист с маской сгиба.
Внутренние ссылки PDF активны поверх страниц, включая Мазмұны. Координаты ссылок и целевой половины учитывают поворот и разделение разворотов. Встроенный PDF уже содержит ссылки, его редактирование не требуется. Для других PDF переходы требуют встроенных внутренних ссылок; сканы без них автоматически не распознаются. При публикации добавьте pdf-links.js.
